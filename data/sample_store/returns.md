# Returns and refunds

## Return window
You can return unused items within 30 days of delivery for a full refund. Returns are free within Estonia.
For other EU countries the return shipping costs 9.90 EUR, deducted from the refund.

## Condition
Boards must be unmounted, with no base or edge damage, and returned in the original packaging.
Waxed or mounted boards can't be returned, but they are still covered by the warranty.

## Refund timing
Refunds go back to the original payment method within 5 working days after the return reaches us.

## Exchanges
To swap a size or model, return the item and place a new order. We don't hold stock for exchanges.
